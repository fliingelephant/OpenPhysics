  <claim>
    For every triple of positive integers \(N,M,K\), characterize, up to the
    equivalence defined below, the complete irredundant set of facet-defining
    linear inequalities of the finite local-realistic correlation polytope
    \(\mathcal{L}_{N,M,K}\) generated by deterministic assignments for \(N\)
    parties, \(M\) measurement choices per party, and \(K\) outcomes per
    measurement.
  </claim>

  <def>
    For a positive integer \(r\), write \([r]=\{1,\ldots,r\}\). A behavior in
    the full conditional-probability representation is an array
    \[
      p=\{p(a|x): a\in [K]^N,\ x\in [M]^N\}
      \in \mathbb{R}^{[K]^N\times [M]^N},
    \]
    where \(x=(x_1,\ldots,x_N)\) is the vector of local measurement choices and
    \(a=(a_1,\ldots,a_N)\) is the vector of local outcomes. Normalization means
    \[
      \sum_{a\in [K]^N}p(a|x)=1,\qquad x\in [M]^N .
    \]

    A deterministic local assignment is a function
    \(s:[N]\times [M]\to [K]\). It defines the deterministic behavior
    \[
      d^s(a|x)=\prod_{i=1}^N \mathbf{1}\{a_i=s(i,x_i)\}.
    \]
    The local-realistic correlation polytope is
    \[
      \mathcal{L}_{N,M,K}
      =
      \operatorname{conv}\{d^s:s\in [K]^{[N]\times [M]}\}.
    \]
    Equivalently, \(p\in \mathcal{L}_{N,M,K}\) if and only if there is a
    probability distribution \(\mu\) on all \(K^{NM}\) deterministic assignments
    such that
    \[
      p(a|x)=
      \sum_{s:\ s(i,x_i)=a_i\ \mathrm{for}\ 1\le i\le N}\mu(s).
    \]

    The affine hull used in this entry is \(\operatorname{aff}
    (\mathcal{L}_{N,M,K})\), equivalently the normalized no-signaling affine
    space in this finite scenario. Thus, for every nonempty
    \(S\subseteq [N]\), the marginal
    \[
      \sum_{a_i:\ i\notin S}p(a|x)
    \]
    depends only on \(\{(a_i,x_i):i\in S\}\), not on the settings
    \(\{x_i:i\notin S\}\). These normalization and marginal-consistency
    relations are treated as affine equalities, not as Bell inequalities.

    A linear inequality is a pair \((c,\beta)\), written
    \[
      \sum_{x\in [M]^N}\sum_{a\in [K]^N}c_{a,x}p(a|x)\le \beta .
    \]
    It is valid for \(\mathcal{L}_{N,M,K}\) if every point of
    \(\mathcal{L}_{N,M,K}\) satisfies it. It is facet-defining if the set of
    points of \(\mathcal{L}_{N,M,K}\) saturating the inequality is a facet
    relative to \(\operatorname{aff}(\mathcal{L}_{N,M,K})\). Two valid
    inequalities are equivalent when they define the same closed halfspace on
    \(\operatorname{aff}(\mathcal{L}_{N,M,K})\). Equivalently,
    \((c,\beta)\sim(c',\beta')\) if there is \(\lambda\gt 0\) such that
    \[
      \sum_{x,a}c'_{a,x}p(a|x)-\beta'
      =
      \lambda\left(\sum_{x,a}c_{a,x}p(a|x)-\beta\right)
    \]
    for all \(p\in\operatorname{aff}(\mathcal{L}_{N,M,K})\); this permits
    affine combinations of the normalization and marginal-consistency
    equalities. Relabelings of parties, settings, or outcomes are not included
    in this equivalence relation. A solution may give orbit representatives
    under such relabelings only if it also specifies the group action that
    recovers all exact facets. Positivity inequalities \(p(a|x)\ge 0\) are
    included when they define facets in this convention.
  </def>

  <known>
    Open Quantum Problems, All the Bell inequalities, Problem 1, asks for the
    linear inequalities characterizing the existence of joint probability
    distributions for all variables in a correlation experiment. The Open
    Quantum Problems list records this as Problem 1 in the Quantum foundations
    category. The Open Quantum Problems page formulates the finite scenario with
    \(N\) subsystems, \(M\) observables per subsystem, and \(K\) outcomes per
    observable, and describes the local-realistic model as the convex polytope
    generated by all assignments of one of the \(K\) values to each of the
    \(NM\) observables.

    The same Open Quantum Problems page says that \((N,M,K)=(2,2,2)\) is solved
    by the CHSH inequalities and that a general solution for all \(N,M,K\) is
    highly unlikely; in the convention of this entry, Fine's complete
    \((2,2,2)\) description consists of positivity facets together with the
    CH/CHSH class. The OQP page therefore lists several more manageable tasks,
    including complete solutions for other small triples, efficient generation
    of new inequalities, infinite families, full-correlation restrictions, and
    quantum violation margins. This entry records only the full finite
    local-polytope characterization in the claim; those smaller tasks are
    progress unless they imply the complete facet classification of
    \(\mathcal{L}_{N,M,K}\) for all positive \(N,M,K\).

    Bell introduced the local-realistic obstruction for quantum correlations,
    and Clauser, Horne, Shimony, and Holt gave the CHSH inequality for the
    bipartite binary setting. Fine proved the joint-probability characterization
    for the \((2,2,2)\) scenario. Pitowsky developed the correlation-polytope
    formulation and emphasized the computational complexity of the associated
    facet problem. Pitowsky and Svozil computed complete tight-inequality data
    for selected small scenarios, including \((3,2,2)\) and \((2,3,2)\), with
    marginal constraints. Werner and Wolf gave a complete family for the
    full-correlation subclass with two dichotomic observables per site for
    arbitrary \(N\). The Werner-Wolf result is a complete solution for that
    projected full-correlation subclass, not for the full conditional-probability
    polytope \(\mathcal{L}_{N,2,2}\) with marginal constraints.
  </known>

  <ask>
    Give, for arbitrary symbolic positive \(N,M,K\), a nonredundant
    parametrization or classification theorem whose instances are exactly the
    equivalence classes of facet-defining valid inequalities of
    \(\mathcal{L}_{N,M,K}\). Degenerate one-party, one-setting, or one-outcome
    cases may be disposed of separately. The answer must prove both validity and
    completeness relative to
    \(\operatorname{aff}(\mathcal{L}_{N,M,K})\), including normalization and
    marginal-consistency conventions. A result covering only fixed small
    triples, only positivity inequalities, only inequalities obtainable from
    lower-order scenarios, only symmetric subclasses, only full-correlation
    projections, or only quantum violation bounds is progress, not a solution,
    unless it implies the complete classification in the claim.
  </ask>

    Return one of: proof, disproof, gap, progress.
    State all assumptions and cite every external theorem used.
